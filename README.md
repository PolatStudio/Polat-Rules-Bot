# 📜 Polat Rules Bot

بوت قوانين احترافي ومتطور من **Polat Studio** لإدارة وتنظيم قوانين الديسكورد بطريقة تفاعلية وفخمة بالكامل داخل السيرفر.

يوفر البوت لوحة تحكم متكاملة تسمح لك بتعديل القوانين، الأزرار، الألوان، البنرات، والروابط مباشرة من داخل الديسكورد بدون الحاجة لتعديل ملفات أو أكواد.

---

## ✨ المميزات

- لوحة تحكم تفاعلية كاملة داخل الديسكورد
- تخصيص كامل لواجهة القوانين
- دعم الأزرار التفاعلية والقوائم الفرعية
- أزرار روابط خارجية
- ردود خاصة Ephemeral للحفاظ على نظافة الشات
- رفع تلقائي للأيقونات والإيموجيات
- حفظ دائم للإعدادات باستخدام SQLite
- تصميم احترافي مناسب للسيرفرات الكبيرة

# 📜 Polat Rules Bot

Professional and advanced Discord rules management bot developed by **Polat Studio**.

The bot provides a fully interactive dashboard allowing administrators to manage rules, buttons, layouts, banners, and links directly inside Discord without editing configuration files.

---

## ✨ Features

- Fully interactive in-Discord dashboard
- Complete rules interface customization
- Advanced buttons & submenu system
- External link buttons support
- Ephemeral responses for clean rule channels
- Automatic emoji & icon uploader
- Persistent SQLite data storage
- Modern UI built for professional communities

---

## 🛠️ Tech Stack

- Discord.js v14
- SQLite
- Discord Components API
